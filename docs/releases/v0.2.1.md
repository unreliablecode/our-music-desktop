## Our Music - Desktop 0.2.1

Each song now has a visible play button. This works in search results, Home recommendations, library pages, playlists, and the queue. Clicking a song's button starts that track, even when another row is selected. Queue buttons preserve the clicked position when the same song appears more than once.

The release also includes themed window controls and dropdowns, cover artwork, local recommendations, playlists, favorites, offline downloads, and a sleep timer.

### Install

1. Download `OurMusic-Desktop-v0.2.1-win-x64.zip` and extract it.
2. Open `OurMusic.Desktop.exe` in the extracted folder. Keep all files together.
3. Install Node.js on PATH for online playback. Restart the app after installation.

Windows 10 or 11 x64 is required. The ZIP includes the .NET runtime and yt-dlp; no separate .NET installation is needed. Local audio playback works offline.

The accompanying SHA-256 file contains the checksum of the ZIP. Source is available under the v0.2.1 tag and remains GPL-3.0 licensed.

The package contains yt-dlp 2026.08.19 and .NET 10.0.6. Component licenses, notices, and source links are included in the `licenses` folder.

### Validation

The smoke checks exercise the actual row buttons, local playback, queue position, saved data, interface styling, and recommendation ranking. Online playback and artwork depend on YouTube availability. Hosted CI omits device-dependent audio checks; those are run on a Windows desktop before publication.
